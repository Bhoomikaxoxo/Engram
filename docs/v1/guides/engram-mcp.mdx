You can let Claude use Engram to manage its own memory in the native desktop app by using the Engram MCP integration! Follow these steps:

1. Clone the `engram-mcp` repo:

```
git clone git@github.com:plastic-labs/engram-mcp.git
```

2. Navigate into the `engram-mcp` folder.

```
cd engram-mcp
```

3. Sync the virtual environment. This package uses [uv](https://docs.astral.sh/uv/), [install](https://docs.astral.sh/uv/#installation) if you haven't.

```
uv sync
```

4. In Claude Desktop, go to the *top left Mac Toolbar* Settings > Developer and click "Edit Config"

5. Add the following (and update paths!):

```
{
  "mcpServers": {
    "Engram": {
      "command": "/path/to/uv",
      "args": [
        "run",
        "--with",
        "mcp[cli]",
        "mcp",
        "run",
        "/path/to/engram-mcp/main.py"
      ]
    }
  }
}
```

<Warning>You probably will need to put the full path to the uv executable in the command field. You can get this by running `which uv` on MacOS/Linux or `where uv` on Windows.</Warning>

6. Restart the Claude Desktop app. Upon relaunch it should start Engram and the tools should be available!

Just note that, by default, the MCP server is set up to use the Engram Demo server, which only persists data for 7 days. If you're using the hosted version of Engram, copy the `.env.template` to a proper `.env` file and update the URL and API key variables accordingly.

## Project Instructions

Finally, Claude needs instructions on how to use Engram. The Desktop app doesn't allow you to add system prompts directly, but you can create a project and paste these [instructions](https://github.com/plastic-labs/engram-mcp/blob/main/instructions.txt) into the "Project Instructions" field.

<Note>Be sure to update the \<app_name\> and \<user_name\> variables in the instructions.txt file.</Note>

Claude should then query for insights before responding and write your messages to storage! If you come up with more creative ways to get Claude to manage its own memory with Engram, feel free to [let us know](https://discord.gg/engram) or make a PR on this [repo](https://github.com/plastic-labs/engram-mcp/tree/main)!
